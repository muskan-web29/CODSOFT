# ROCK_PAPER_SCISSORS GAME

## DESCRIPTION
This project is a simple Rock-Paper-Scissors game built using pyton, where the user competes against the computer, which randomly selects its move. The program then compares both choices and declares the winner based on the game rules.

## FEATURES
- User chooses rock, paper or scissors
- Computer makes a random choice
- Determines the winner based on game rules
- Displays the result clearly
- Option to play multiple rounds( if implemented)
